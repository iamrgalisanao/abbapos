# Report Definitions

## Daily Sales Report (Z-Report)
- Summary: Total sales, total tax, total discounts for the day.
- Fields: Gross Sales, Net Sales, VAT Amount, Net of VAT, Service Charge.

## Shift Report (X-Report)
- Summary: Summary of activity for a specific cashier shift.
- Fields: Opening Cash, Tenders Received, Expected Cash, Short/Over.
